## Finding Station IDs for Other Cities

If a city is not listed here, find its station ID by:

1. Visit `https://weather.cma.cn/`
2. Search for the city name
3. The station ID will appear in the URL: `https://weather.cma.cn/web/weather/{station_id}.html`
